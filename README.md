#提取+（拉+）

一个极致轻量、纯Kotlin的Android端APK提取与管理增强小工具。由极客独立打造，坚持纯粹极简路线，向那些信号爆炸、满是广告和鳄鱼的软件宣战。

## 💡核心特点

-  **极限轻量**：安装包仅200K左右，真正实现麻雀虽小、五脏俱全。
-  **纯粹重构**：全面采用Kotlin与Android API手工构建，**零第三方库、零第三方依赖**，甚至不依赖任何可视化框架。
-  **绝对彻底**：零广告、零弹窗、零强制关注、零诱导打赏，回归软件最纯粹的本质。
-  **匠心彩蛋**：代码中引入了一些极客独特的小彩蛋。
